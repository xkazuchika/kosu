# v0.10.0 — 月次配分と、時間だけで完了できる工数確定

「誰が、どの案件に、どのくらい時間を使う予定か」を一覧で確認できるようになりました。月末は単価や金額を設定しなくても工数を確定でき、簡易原価の確認・承認は必要な場合だけ行えます。

## 主な変更

- 管理者の月次予定画面に、担当者×案件の配分一覧を追加。複数ロールの時間を案件ごとに合算し、社内作業も含めて表示します。
- 任意の稼働可能時間と予定確認から、月単位の「予定上の余力」「予定超過」を表示します。未確認の残りは仮の値として区別し、未設定を0時間と扱いません。
- 月次予定・稼働可能時間の変更やCSV取り込みで、該当担当者・月だけ予定確認を解除します。画面表示後に変更された古い内容での確認も拒否します。
- 月次締めを「工数レビュー・確定」と「任意の原価レビュー・承認」に分離しました。全対象者の提出と勤務時間・配賦時間の一致で工数管理を完了できます。
- 工数確定後も通常の時間・予定・CSV等の変更を保護します。欠損原価だけは、原価未確認の条件下で管理者が明示単価と理由を記録して補正できます。
- 修正時の理由付き再オープンで工数・原価の両方を未締めに戻し、提出記録は実績変更まで維持します。原価承認済みの財務スナップショットは従来どおり保持します。

## アップグレード

1. 入力を止め、READMEのSQLiteバックアップ手順で移行前データを保存してください。稼働中のDBファイルだけを直接コピーしないでください。
2. v0.10.0へ更新し、通常の起動手順でmigrationを適用します。v0.9.0からは `0008_monthly_plan_reviews.sql` と `0009_sleepy_sabra.sql` が追加されます。新しい設定項目はありません。
3. 既存予定・稼働可能時間の値は維持され、予定確認は未確認から始まります。過去の保護月を確認のためだけに再オープンする必要はありません。
4. 旧原価の未締め・レビュー中・承認済みは、工数の未確定・レビュー中・確定済みに対応付けられます。既存の原価状態・履歴・財務保存値を保持します。旧レビュー中の月は、工数を確定してから原価承認を続けられます。
5. 更新後、月次配分一覧と、既存の工数・原価の状態を確認してください。

## ロールバックの注意

**新しいDBのまま旧アプリだけに戻してはいけません。** 旧アプリは工数だけが確定した月の保護を認識しません。

戻す場合はアプリを停止し、移行後の入力を別途保存してから、移行前バックアップと対応する旧アプリをセットで復元してください。復元によって戻るデータ期間を利用者へ知らせてください。DBの移行は前方のみを想定しています。

## 対象範囲

余力は月単位の計画上の目安で、週ごとの空きや担当できる業務を保証しません。予定確認・稼働可能時間・日次予定・金額は工数確定の必須条件ではありません。

簡易原価は直接人件費だけです。外注費・経費・間接費・税・請求・入金・給与計算・会計上の締めは対象外です。
