# Windowsで直接起動する

## 必要なもの

- Windows x64、書き込み可能なローカルフォルダー
- [Node.js](https://nodejs.org/en/download) 22.22以上。まずは22系の対応版を選んでください。npmも同梱されています。
- npmパッケージとSQLiteのネイティブ部品をダウンロードできるネットワーク
- ChromeやEdgeなどのChromium系ブラウザ

Docker、Git、別のDBサーバーは不要です。Node.jsの導入が組織の制限で認められていない場合は、管理者に導入先を相談してください。

## 1. ソースを取得する

[安定版リリース](https://github.com/xkazuchika/kosu/releases/latest)を開き、`Source code (zip)` を取得して展開します。ZIPを開いただけの状態で実行せず、フォルダーとして展開してください。Gitを使う場合もリリースのタグを指定してクローンします。

展開後に `package.json`、`install.bat`、`start.bat` があるフォルダーを開きます。導入ファイルがない版は、その版のREADMEの手動手順を使ってください。既に取得済みなら、この取得操作は不要です。

## 2. 初回の準備

`install.bat` をダブルクリックします。次の処理を順番に行います。

1. Node.jsと設定を確認
2. 初回だけ `.env` を生成し、ランダムなシークレットを保存
3. ロックファイルに従って依存関係を導入
4. アプリをビルド
5. データベースを準備し、整合性を確認

「導入の準備が完了しました」と表示されたら、表示されたキー操作でウィンドウを閉じます。初回はダウンロードとビルドに時間がかかります。

コマンドプロンプトで進める場合は、取得したフォルダーで実行します。

```bat
install.bat
```

共通処理を直接呼ぶ場合は `npm run setup:local` でも同じ準備ができます。通常の `npm start` はこの導入用の設定読み込み・起動確認を含まないため、次の `start.bat` を使います。

## 3. 起動して初期設定する

`start.bat` をダブルクリックします。移行・整合性検査後に起動し、ヘルスチェックが成功すると次のURLが表示されます。

```text
http://localhost:3000
```

表示されたURLをブラウザで開き、ワークスペース名、管理者氏名、メールアドレス、パスワードを入力します。設定済みのデータならログイン画面へ進みます。

**起動したウィンドウは開いたままにします。** 停止する場合はそのウィンドウで `Ctrl+C` を押します。確認メッセージが出る場合は指示に従って終了してください。再起動は `start.bat` をもう一度実行します。共通コマンドは `npm run start:local` です。

この起動方法はビルド済みアプリを本番設定で実行し、PC内の `127.0.0.1` だけで待ち受けます。localhost以外のHTTP共有ではなく、チームで使う場合はHTTPS終端を用意した管理者向け運用へ進んでください。本番の署名済みセッションとSecure Cookieを使用します。

## 設定とデータ

- 設定の既定は取得したフォルダー内の `.env` です。生成時にデータ保存先とシークレットを保存します。
- データは既定で同じフォルダーの `data/kosu.sqlite` に保存します。起動時に絶対パスが表示されます。
- 設定済み環境変数が `.env` より優先されます。環境変数を変えると保存先も変わるため、表示された保存先を確認してください。
- `PORT` は1024〜65535の整数で指定します。既定は3000です。`HOST` は `127.0.0.1` を使います。
- 別の設定ファイルは `install.bat --config "C:\kosu-settings\.env"`、`start.bat --config "C:\kosu-settings\.env"` のように、準備と起動で同じファイルを指定します。相対パスはアプリのフォルダーを基準にします。
- 再準備でも既存 `.env`、シークレット、データは維持します。不正な値やサンプルのシークレットはエラーで停止し、自動的に別設定へ切り替えません。
- 更新前には停止してバックアップします。既存アプリフォルダーを削除して取得し直す方法は使わないでください。

`.env` は秘密情報です。共有、Gitへの追加、エージェントの完了報告への貼り付けは不要です。

## うまく起動しないとき

| 表示・状態                 | 次の操作                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Node.js 22.22以上が必要    | 対応するNode.jsを導入し、コマンドプロンプトを開き直す                                                        |
| npmが見つからない          | npmを含むNode.jsの配布版を導入する                                                                           |
| 依存関係の導入に失敗       | 直前のエラーとネットワーク制限を確認する。ネイティブ部品の取得失敗ではNode.js・OS・CPUの組み合わせを確認する |
| シークレットのエラー       | `.env` の `KOSU_SESSION_SECRET` に固有の32文字以上の値を設定する。既存設定を勝手に置換しない                 |
| データ保存先へ書き込めない | `KOSU_DATA_DIR` を書き込み可能なフォルダーへ設定する                                                         |
| ビルドがない               | `install.bat` を実行する                                                                                     |
| ポートを使用できない       | 自分が起動したアプリを停止するか `.env` の `PORT` を変える。別のプロセスは終了しない                         |
| 整合性検査に失敗           | 表示されたエラーを確認し、[運用手順](operations.md)に従ってバックアップを確認する                            |

更新・バックアップ・復元は [運用手順](operations.md) を参照してください。
