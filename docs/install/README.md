# kosuを使い始める

インストールから起動まで、エージェントに任せられます。自分で進める手動手順も用意しています。

| 方法                 | 必要なもの                                                             | 手順                             |
| -------------------- | ---------------------------------------------------------------------- | -------------------------------- |
| エージェントに任せる | ファイル操作・ネットワーク取得・コマンド実行ができるエージェント       | [コピーするプロンプト](agent.md) |
| Windowsで直接起動    | Windows x64、Node.js 22.22以上（22系を推奨）、書き込み可能なフォルダー | [Windowsの手動導入](windows.md)  |
| Dockerで起動         | DockerとDocker Compose                                                 | [Dockerの手動導入](docker.md)    |

Dockerを使えない環境ではWindowsの直接起動を選べます。Gitがなくても、安定版のZIPを展開して導入できます。直接起動では別途DBサーバーを用意する必要はありません。

## 最短の流れ

1. [安定版リリース](https://github.com/xkazuchika/kosu/releases/latest)からソースを取得し、ZIPの場合は展開します。
2. 選んだ方法で設定・導入を進めます。Windowsでは `install.bat`、次に `start.bat` を実行します。
3. 表示されたURLをブラウザで開き、ワークスペースと最初の管理者を設定します。

**この導入ガイドと起動ファイルが含まれる版で利用できます。** 公開済みの安定版にまだ含まれていない場合は、その版のREADMEの手動手順を参照してください。エージェントは無断で開発中のmainへ切り替えません。

停止・更新・バックアップ・復元は [運用手順](operations.md)、画面操作は [ユーザーガイド](../user-guide.md) を参照してください。

第一段階の直接起動はWindows x64を対象とし、Chromium系ブラウザのlocalhostアクセスを確認対象にしています。Node.js同梱ZIP、Windowsサービスへの登録、Windows ARM、HTTPSの自動構築は今後の対応です。
