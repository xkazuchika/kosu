# Kosu OpenSpec Notes

The current public v0.1 scope is defined by `openspec/specs/`.

`openspec/changes/archive/` contains historical change artifacts from earlier MVP planning and implementation. Archived artifacts may mention features that are no longer part of the v0.1 public scope, including financial reporting, gross-profit reporting, full planned-versus-actual reporting, and full resource planning.

For v0.1 release decisions, use these sources in order:

1. `openspec/specs/` for current requirements.
2. `README.md` for public product positioning and deployment notes.
3. `docs/release-checklist.md` for release verification and known issues.

Do not treat archived change text as the active release scope.
