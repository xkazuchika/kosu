- [ ] 2.1 提出と配賦一致だけを扱う工数完全性サービスを抽出する。単価・金額なし、予定・capacityなし、0時間提出で通り、未提出・不一致は対象者・日付付きで失敗することをテストする。
- [ ] 2.2 工数レビュー・確定を実装し、管理者権限と完全性を transaction 内で再確認する。古い画面からの操作、非法な遷移、イベント保存失敗で状態も rollback することを検証する。
- [ ] 2.3 原価レビュー・承認に工数確定の前提を追加する。欠損原価は引き続き阻止し、工数確定だけでは財務 snapshot を作成・選択しないこと、移行済みレビューを継続できることを検証する。
- [ ] 2.4 欠損原価専用補正を工数保護中にも対応させる。管理者・理由・明示単価・選択月と元データの月の原価保護を検証し、時間・提出・予定確認・財務 snapshot が変わらないテストを追加する。
